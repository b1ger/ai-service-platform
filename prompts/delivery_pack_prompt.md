# Delivery Pack Prompt

## Goal
Generate a clean delivery document for a completed workflow package.

## Input
- completed workflow
- template list
- usage notes
- important exceptions
- recommended next step

## Required output
- summary
- current issue
- proposed workflow
- what is improved
- templates included
- how to use
- exceptions to watch
- recommended next step

## Constraints
- keep language client-friendly
- do not mention internal prompt mechanics
- do not include speculative future features
- highlight what still needs human review

## Acceptance criteria
- document can be sent to a real client with minimal editing
