# Workflow Map Prompt

## Goal
Generate a workflow map for one narrow business process.

## Input
- business segment
- workflow name
- current-state notes
- target improvement
- known constraints

## Required output
- workflow name
- purpose
- trigger
- inputs
- core steps
- decision points
- outputs
- human-in-the-loop steps
- exceptions
- success criteria
- notes

## Constraints
- no broad transformation claims
- keep the workflow specific
- include at least one manual review point where appropriate
- do not assume unavailable systems or tools

## Acceptance criteria
- workflow is practical enough to guide a real pilot
