# Intake Prompt

## Goal
Turn a raw client message into a structured intake summary.

## Input
Raw inbound message, notes, or transcript.

## Required output
- request summary
- lead category
- missing information
- suggested next step
- draft reply

## Constraints
- do not invent facts
- keep reply short
- ask only necessary questions
- label uncertainty clearly

## Acceptance criteria
- summary can be reused in a CRM, document, or daily summary
