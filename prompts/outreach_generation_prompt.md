# Outreach Generation Prompt

## Goal
Draft a short niche-specific outreach message.

## Input
- target segment
- pain point
- desired CTA

## Required output
- one concise message
- clear value proposition
- one CTA

## Constraints
- no heavy AI wording
- no long intro
- no multiple CTAs
- no pressure-heavy sales tone

## Acceptance criteria
- message sounds natural enough to send directly
