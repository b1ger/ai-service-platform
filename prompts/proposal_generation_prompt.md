# Proposal Generation Prompt

## Goal
Draft a short, practical pilot proposal for one selected workflow.

## Input
- client or prospect summary
- selected workflow
- key pains
- included scope
- excluded scope
- expected value

## Required output
- client
- request summary
- proposed solution
- scope
- workflow / delivery
- expected outcome
- next step

## Constraints
- keep the proposal simple
- do not promise end-to-end transformation
- avoid generic buzzwords
- make scope boundaries explicit

## Acceptance criteria
- a small business owner can read this and understand what they are buying
