# Proposal — Furniture Intake Workflow Pilot

## Client
- Name: Andrii
- Business: OakForm Studio
- Contact: Instagram / Viber

## Request summary
Custom furniture requests arrive in an unstructured way.
The owner repeatedly asks for dimensions, materials, and timing before understanding whether a quote is realistic.

## Proposed solution
We start with one workflow:
custom order intake and clarification.

This pilot will:
- convert requests into a structured brief
- define missing-details logic
- standardize the clarification reply
- classify requests by quote readiness
- create a short daily owner summary

## Scope
- included:
  - intake workflow map
  - clarification template
  - qualification logic
  - quote-ready checklist
  - summary template
- not included:
  - final pricing logic
  - production scheduling
  - website form implementation

## Workflow / delivery
1. review current inquiry examples
2. define structured intake fields
3. create template and logic pack
4. deliver short usage guide

## Expected outcome
- cleaner request briefs
- faster prioritization
- less owner time spent on repetitive clarification

## Next step
Confirm the pilot and share 5 recent inquiry examples for tuning.
