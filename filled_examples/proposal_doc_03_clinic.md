# Proposal — Appointment Reminder Workflow Pilot

## Client
- Name: Olena
- Business: SmileCare Dental
- Contact: phone / Instagram

## Request summary
Appointment reminders and confirmation follow-ups are currently inconsistent and require too much manual checking by the administrator.

## Proposed solution
We start with one workflow:
appointment reminder and confirmation follow-up.

This pilot will:
- standardize reminder wording
- define follow-up for missing confirmation
- create a daily pending confirmation summary
- clarify what stays manual in sensitive cases

## Scope
- included:
  - reminder workflow map
  - reminder template
  - follow-up reminder template
  - daily summary format
  - usage guidance for admin
- not included:
  - medical communication automation
  - patient record integration
  - sensitive-case automation

## Workflow / delivery
1. define current reminder path
2. create standard reminder logic
3. prepare template pack
4. deliver admin-friendly guide

## Expected outcome
- less manual reminder work
- better visibility into pending confirmations
- more consistent communication

## Next step
Approve pilot scope and identify one appointment type to use as the first test case.
