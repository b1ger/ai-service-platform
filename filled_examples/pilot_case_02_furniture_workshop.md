# Pilot Case — Furniture Workshop

## Client overview
- Client name: Andrii
- Business name: OakForm Studio
- Segment: custom furniture workshop
- Team size: 3
- Main contact: workshop owner
- Contact channel: Instagram + Viber

## Current-state problem
- Clients send photos and rough ideas without dimensions.
- The owner repeatedly asks the same clarification questions.
- Serious and non-serious inquiries look similar at first.
- There is no clean intake format before pricing discussion starts.

## Workflow selected for pilot
- Workflow name: custom order intake and clarification
- Why this workflow first: it affects quote quality and wastes owner time daily
- Expected business value: cleaner requests and faster prioritization

## Inputs
- Source of inbound requests: Instagram, Viber
- Current tools used: chat apps, handwritten notes
- Current communication channels: DM, messenger
- Existing templates or scripts: a few old saved replies

## Proposed automation logic
1. Normalize every request into a short structured brief.
2. Identify missing dimensions, materials, style, and timing.
3. Send a concise clarification message.
4. Classify the lead as ready for quote, needs details, weak fit, or inspiration-only.
5. Produce a daily owner summary of quote-ready requests.

## Deliverables
- custom order intake template
- clarification message template
- lead classification logic
- quote-ready checklist
- daily summary template

## Risks / constraints
- missing information: dimensions often unavailable
- limitations: pricing still requires owner review
- approval dependencies: design feasibility remains manual

## Delivery notes
- what was delivered: intake structure, reply templates, qualification logic, summary format
- what required manual editing: material options adjusted to client's real offering
- what should be standardized next: quote request sheet

## Feedback
- client reaction: immediately saw value in not repeating the same questions
- useful feedback: clients should not feel interrogated in the first reply
- objections: wants short messages only
- follow-up opportunity: proposal/quote template cleanup

## Reusable learnings
- repeated pain point: missing dimensions and materials
- reusable template candidate: missing-details request for furniture orders
- possible productization signal: furniture intake assistant
