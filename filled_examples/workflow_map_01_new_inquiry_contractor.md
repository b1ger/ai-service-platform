# Workflow Map — Contractor New Inquiry Flow

## Workflow name
New Inquiry Intake and Estimate Follow-Up

## Purpose
Reduce lost estimate opportunities and remove repeated manual questioning.

## Trigger
A new inquiry arrives through Instagram DM.

## Inputs
- client message
- contact name if available
- photos if available
- stated service request

## Core steps
1. capture the message
2. summarize the request into a structured brief
3. classify the request as estimate / info / weak fit / urgent
4. identify missing details
5. send first-response template
6. schedule follow-up if the client goes silent
7. include item in daily summary

## Decision points
- If missing photos or dimensions:
  - send clarification request
- If the request is clearly outside service scope:
  - send polite non-fit reply
- If urgent:
  - highlight in daily summary

## Outputs
- structured lead brief
- response draft
- follow-up flag
- daily summary item

## Human-in-the-loop steps
- owner reviews serious estimate cases
- owner decides final pricing path

## Exceptions / edge cases
- incomplete contact info
- urgent repair request outside schedule
- duplicate message
- request outside service area

## Success criteria
- fewer missed estimate leads
- less repeated questioning
- better visibility of open conversations

## Notes
This workflow is ideal as a starter pilot because value is easy to explain.
