# Proposal — Contractor Inquiry Workflow Pilot

## Client
- Name: Serhii
- Business: RenovPro Team
- Contact: Instagram / phone

## Request summary
The current inquiry process depends too much on manual chat handling by the owner.
Important details are often missing from first contact.
Estimate follow-up is inconsistent.

## Proposed solution
We start with one workflow:
new inquiry intake and estimate follow-up.

This pilot will:
- structure new inquiries
- standardize the first reply
- define a missing-details request
- add a simple follow-up step
- create a short daily summary format

## Scope
- included:
  - one workflow map
  - response templates
  - clarification template
  - follow-up logic
  - daily summary format
- not included:
  - final pricing automation
  - full CRM implementation
  - multi-channel system integration

## Workflow / delivery
1. review the current process
2. map the target workflow
3. prepare template pack
4. deliver usage notes

## Expected outcome
- fewer missed estimate requests
- less repeated manual messaging
- more visible open inquiries

## Next step
Approve the pilot scope and start with one live workflow.
