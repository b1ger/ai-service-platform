# Pricing Packages V1

## Goal
Keep packages simple, easy to explain, and tied to one workflow at a time.

## Package A — Starter Workflow
### Best for
Businesses that want to fix one repetitive process first.

### Includes
- one workflow review
- one workflow map
- response templates
- basic follow-up logic
- short delivery guide

### Good examples
- new inquiry flow
- missed reply recovery
- appointment reminder flow

## Package B — Core Operations Pack
### Best for
Businesses that need a small but connected routine system.

### Includes
- 2 to 3 workflows
- intake summary logic
- follow-up logic
- reminder logic
- daily summary format
- template pack

## Package C — Extended Operations Pack
### Best for
Businesses that want a broader operational cleanup.

### Includes
- multiple workflow maps
- richer message template set
- daily visibility structure
- onboarding and usage notes
- iteration / refinement window

## Pricing principles
- define revision limits
- define exactly what is included
- sell business outcome, not prompt count
- keep pilot offers time-bounded
