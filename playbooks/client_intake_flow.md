# Playbook: Client Intake Flow

## Goal
Gather the minimum required information to understand the client request.

## Intake fields
- client name
- business name if relevant
- requested service
- location if relevant
- budget range if relevant
- preferred timing
- main pain point
- contact channel
- supporting files or notes

## Logic
1. collect stated information
2. identify missing critical data
3. ask only necessary follow-up questions
4. summarize request in a structured format
5. prepare handoff or next response

## Output
- structured brief
- missing data list
- suggested next step

## Acceptance criteria
- summary is readable by another team member
- missing information is explicit
- next step is unambiguous
