# Playbook: Daily Lead Summary

## Goal
Provide a simple daily summary for the owner or manager.

## Include
- total new inquiries
- classified lead counts
- urgent items
- follow-up pending items
- missing information items
- recommended priorities

## Format
- short summary block
- categorized items
- action list

## Output template
1. overview
2. hot leads
3. waiting for response
4. needs clarification
5. action recommendations

## Acceptance criteria
- summary fits in one quick read
- priorities are obvious
- owner can act without reading all raw messages
