# Playbook: Follow-Up Flow

## Goal
Reduce lost leads by standardizing follow-up.

## Trigger cases
- inquiry received but no reply from client
- estimate sent but no answer
- appointment interest but no confirmation
- incomplete intake information

## Steps
1. identify silence window
2. determine follow-up reason
3. generate concise follow-up message
4. define next follow-up timing
5. stop follow-up after defined threshold if no reply

## Message rules
- concise
- polite
- low-pressure
- clear next step
- no spammy tone

## Output
- follow-up message
- reason code
- recommended next action
- final stop rule

## Acceptance criteria
- follow-up tone stays professional
- message includes one clear action
- no excessive repeated nudging
