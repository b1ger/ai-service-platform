# Playbook: Niche Assistant Flow

## Goal
Evaluate whether a repeated workflow is ready to become a narrow assistant.

## Inputs
- repeated service case data
- common client requests
- stable workflow examples
- reusable outputs

## Steps
1. identify repeated workflow
2. define exact use case
3. list minimal required inputs
4. define acceptable outputs
5. document rules and constraints
6. identify review points
7. recommend implementation form

## Possible implementation forms
- internal operator tool
- structured prompt workflow
- form-based assistant
- chat assistant
- lightweight web app

## Output
- assistant candidate summary
- input schema
- output schema
- risk notes
- productization recommendation

## Acceptance criteria
- use case is narrow
- input requirements are clear
- output is predictable
- workflow has real demand
