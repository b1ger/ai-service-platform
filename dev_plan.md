# Dev Plan

## Goal
Use Gemini CLI as the main execution environment for building and refining a service business focused on routine automation for small businesses.

## Current stage
Phase 1: Automation-first delivery.

## Current priorities
1. package one clear starter offer
2. run discovery with real prospects
3. deliver 3 pilot cases
4. convert reusable parts into templates and playbooks
5. prepare for document-service expansion only after stable automation delivery

## Constraints
- do not overbuild
- do not start with SaaS
- do not expand to too many niches
- keep manual QA on every client output
- prefer markdown artifacts over hidden chat context

## Immediate deliverables
- outreach messages
- discovery notes
- workflow maps
- pilot proposals
- delivery docs
- reusable templates

## Success criteria for this stage
- 3 real or realistic pilot cases documented
- one repeatable starter workflow offer
- a reusable proposal pack
- stable Gemini CLI repo instructions
- clear signals for which workflow to sell first

## Near-term next steps
1. pick first outreach segment
2. send outreach
3. run discovery
4. fill discovery notes
5. generate workflow review
6. send proposal
7. deliver pilot
8. document learnings
