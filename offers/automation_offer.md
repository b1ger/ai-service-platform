# Automation Offer

## Working title
Routine Automation for Small Businesses

## Core promise
We help small businesses reduce manual routine, respond faster to clients, and stop losing leads.

## What we solve
- missed inquiries
- inconsistent responses
- forgotten follow-ups
- no intake structure
- poor visibility into daily inbound demand

## Core deliverables
- one mapped workflow
- lead intake logic
- message and response templates
- follow-up logic
- reminder logic
- daily summary format
- handoff / usage notes

## Package ideas

### Mini
- 1 workflow
- 1 intake path
- up to 3 message templates
- basic follow-up logic
- short delivery document

### Standard
- 2 to 3 workflows
- intake + follow-up + reminders
- template pack
- daily summary logic
- onboarding notes

### Extended
- multiple workflows
- richer message logic
- team usage guidance
- template library
- support / iteration window

## Good entry offer
"Let's fix one routine process first."

## Ideal first use cases
- new inquiry handling
- missed response recovery
- follow-up after estimate request
- reminder before appointment
- daily summary for owner

## Proof points to build over time
- response time reduced
- fewer missed inquiries
- more consistent communication
- easier handoff across the team
