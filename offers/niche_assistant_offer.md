# Niche Assistant Offer

## Working title
Niche AI Assistant Blueprint

## Purpose
Turn repeated service workflows into a narrow AI assistant for one use case.

## Suitable assistant candidates
- client intake assistant
- proposal drafting assistant
- project brief assistant
- inbound inquiry summarizer
- FAQ response assistant

## Productization trigger
Move toward this offer only after repeated patterns appear across multiple real client cases.

## Deliverables
- use case definition
- target user
- minimal required input
- output schema
- workflow logic
- validation rules
- implementation recommendation
