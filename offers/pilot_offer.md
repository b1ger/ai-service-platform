# Pilot Offer

## Purpose
Create a low-friction entry offer for the first real clients.

## Core promise
We fix one repetitive communication workflow so your business loses fewer leads and spends less time on manual replies.

## What is included
- short discovery
- workflow review
- one mapped process
- response templates
- follow-up or reminder logic
- short delivery document

## Good pilot workflows
- new inquiry handling
- estimate request follow-up
- appointment reminder flow
- daily inquiry summary

## Pilot conditions
- limited scope
- one clear workflow
- fast feedback loop
- feedback expected after delivery

## Success signal
The client sees immediate clarity and wants either:
- another workflow
- ongoing support
- document cleanup help later
