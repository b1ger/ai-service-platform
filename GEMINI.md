# GEMINI Project Instructions

## Project mission
You are helping build a service business focused on small business routine automation first, then document repackaging, and later a niche AI assistant.

## Current priority
Phase 1 only:
small business routine automation.

Do not optimize for future product features unless directly useful for current service delivery.

## Primary workflows
- client intake structuring
- inquiry classification
- response draft generation
- follow-up drafting
- reminder workflow design
- daily summary generation
- workflow documentation
- template creation
- delivery package drafting

## Non-goals for current phase
- do not design a broad SaaS platform
- do not invent complex integrations unless requested
- do not assume enterprise-scale requirements
- do not over-engineer architecture
- do not create fake ROI claims

## Working rules
- prefer reusable markdown artifacts
- preserve simple folder structure
- create explicit checklists
- separate templates, prompts, playbooks, and client-specific materials
- mark assumptions clearly
- when facts are missing, ask concise operational questions or label missing inputs
- never hallucinate client business details

## Output quality bar
Every deliverable should be:
- structured
- practical
- easy to send to a client
- easy to reuse internally
- specific to one workflow or one problem
- written in clear business language

## File creation preferences
When generating files:
- use markdown
- use clear headings
- prefer checklists and sections over long prose
- include acceptance criteria where useful
- create templates that can be reused with minimal edits

## Client delivery principles
For each client workflow, prefer:
1. current-state summary
2. identified problems
3. proposed automation logic
4. message templates
5. exceptions / edge cases
6. handoff notes
7. next-step recommendation

## Safety and privacy
- do not include secrets in files
- do not invent legal guarantees
- do not claim guaranteed revenue improvements
- treat client examples as confidential
- prefer anonymized examples for reuse

## Preferred style
- concise
- operational
- structured
- reusable
- honest about uncertainty

## Future expansion reminder
After multiple automation cases are completed, identify repeated document workflows and repeated intake patterns that can be turned into:
- document service packages
- niche assistant blueprints
