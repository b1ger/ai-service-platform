# Demo Case 02 — Furniture Workshop Lead Handling

## Scenario
A custom furniture workshop receives requests in chat with photos, rough dimensions, and incomplete requirements.

## Problems
- incomplete information at first contact
- repeated clarification messages
- no standard intake structure
- difficult prioritization of serious leads

## Proposed workflow
1. normalize incoming request into a structured brief
2. identify missing dimensions or requirements
3. send a concise clarification request
4. classify lead quality
5. generate owner-friendly summary

## Deliverables
- client intake template
- clarification response template
- lead classification logic
- daily summary format
- workflow notes

## Expected value
- cleaner briefs
- faster quote preparation later
- better lead prioritization
