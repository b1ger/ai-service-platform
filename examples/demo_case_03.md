# Demo Case 03 — Appointment Reminder and Follow-Up

## Scenario
A local service business has frequent appointment requests but inconsistent confirmation and reminder handling.

## Problems
- clients forget appointments
- staff sends reminders inconsistently
- no standard wording
- no visibility into pending confirmations

## Proposed workflow
1. classify booking status
2. send reminder template at the right time
3. send follow-up if confirmation is missing
4. summarize pending actions daily

## Deliverables
- reminder template
- follow-up reminder template
- booking status logic
- pending action summary format

## Expected value
- fewer missed appointments
- more consistent communication
- less manual checking
