# Demo Case 01 — Contractor Inquiry Flow

## Scenario
A small contractor team receives inquiries through Instagram and phone, but most follow-up is handled manually by the owner.

## Problems
- messages are answered inconsistently
- details get lost between chat and calls
- estimate requests are not followed up reliably
- owner repeats the same questions manually

## Proposed workflow
1. capture new inquiry details in a structured format
2. classify request type
3. send a first-response template
4. request missing job details
5. trigger follow-up if no answer
6. include inquiry in daily owner summary

## Deliverables
- intake template
- first-response template
- follow-up template
- daily summary template
- workflow map

## Expected value
- fewer missed estimate opportunities
- less manual retyping
- faster response to serious leads
